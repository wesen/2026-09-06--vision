Shared evidence and timing

A frame's presentation timestamp (PTS) is its time in the video. Frame number alone is insufficient for variable-rate video. For a requested sample rate f, the decoder selects the first frame at or after each point start + k / f, excludes frames at the end, and removes duplicates. The thumbnails show actual decoded inputs; browser seeking is only a viewing convenience.

All ranges are half-open: [start, end). A crop is stored as exact integer pixels as well as the normalized selection. Every source and selected PNG has a SHA-256 identity. When you change a control, you create a new experiment; an earlier result retains its own settings.

Offline component runs can use the whole selected range. Causal replay additionally restricts evidence by availability time and enforces worker queues. A late answer must not appear in an earlier as-of view. Open the replay viewer to study that distinction.

Guide: controlled comparisons and review

Identical video bytes, selected timestamps and image hashes establish matched visual evidence. Changing only the model is a model intervention. Changing a crop changes the input. Different feature spaces can be compared through ranked windows, but their vectors cannot be mixed and their score scales are not calibrated against one another.

A saved review labels a run correct, incorrect, or unjudgeable and records your explanation. It never overwrites the prediction or changes the train/development/test partition. A single reviewed case is useful for diagnosing a failure; it is not a population-level accuracy estimate.

Guide: ridge action heads and frozen features

The action classifier maps an embedding x to class scores s = (x − mean) W + bias and chooses the largest score. Ridge training penalizes the squared weight norm to control fitting. These scores are not calibrated probabilities. Native and pooled heads were trained separately and require their matching feature spaces.

This view inspects the frozen benchmark predictions after checking source and artifact identity. It does not execute a new action model and does not retime its windows to your preview grid. Each row reports its original window and actual input timestamps. The benchmark used weak program-interior labels; its results are not reviewed dense-event accuracy.
